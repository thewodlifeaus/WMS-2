Desk set up

ONCE PER PC
  1. Set the label printer as this PC's default printer (Windows Settings → Printers).
  2. Make a desktop shortcut with this target, so labels print without a pop-up:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --user-data-dir=C:\TWLWMS\chrome --app=https://wms-nu-topaz.vercel.app/pack
  3. Open the shortcut, sign in, choose the desk, click Connect scale, then Test print.
