How it works. Shopify free = Shopify on hand (TWL location) minus committed (sold, not sent yet). WMS free = units in bin locations minus units still to pick for open orders. Difference = WMS free minus Shopify free. + = more in the bins than Shopify thinks, − = fewer in the bins.
Green = match (0)   Amber = 1 to 2 units out   Red = 3 or more units out, or the item is only in one system.
Shopify is read once when you press Get latest; the WMS side is live each time you run the report. Orders reach the WMS from ShipStation every 5 minutes, so a brand-new order can show as a small difference until it arrives.
